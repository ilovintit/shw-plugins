# 特殊形态：Node 服务栈

### 适用场景

AI 机器人连接器等后端服务性质（非浏览器前端，是 Node 服务进程）。

### 技术选型清单

| 层 | 技术 | 说明 |
|---|------|------|
| 运行时 | Node.js + TypeScript | |
| Web 框架 | Express | |
| AI SDK | 按需（如 OpenAI SDK、企微 AI 机器人 SDK） | 看具体对接 |
| 测试 | vitest | |

### 关键约定

- **这是服务不是前端**：没有浏览器、没有 Vue 组件、没有路由组件库。
- **长驻进程**：作为 Node 服务部署，注意进程管理（pm2 / 容器）。
