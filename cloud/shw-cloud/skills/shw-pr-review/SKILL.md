执行前读取 [cloud-runtime.md](cloud-runtime.md)，按实际工具与工作区提供者执行。

执行前必须读取 `shw-issue-gate`；修改前读取 `shw-workspace` 并确认项目、目录、Issue 与所有权。项目外只读，未知修改不覆盖；能力缺失不扩大授权。

# 变更审查

读取完整 diff、Issue AC、当前 PRD/技术方案和相关上下文，检查正确性、权限、状态流转、数据/接口兼容、安全、部署影响、未知改动与范围泄漏。按风险给出路径/行位置、触发条件、影响和修复建议；没有发现不等于证明无缺陷。

业务/权限/状态改动必须和 PRD 同变更；API/数据/架构改动必须和技术文档同变更。区分已实现规格与待实现方案。文档细查可加载 `shw-docs-review`，跨边界设计加载 `shw-design-review`。

开发阶段必须执行类型检查、适用 lint/静态检查及本次改动涉及的单元与单模块 API 快速测试；全量 E2E、VRT、全量 API 等长周期回归集中到 dev→main 集成。必要构建、部署正常执行，tag 不新增测试阶段；检查通过不能代替人工验收。

报告已检查范围、未解决问题、必要人工裁决与未验证项。审查与人工体验各有证据，不互相代替。模型/工具可用性由宿主适配，不强制特定本地 profile 或 CLI。
