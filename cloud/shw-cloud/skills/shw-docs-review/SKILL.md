执行前必须读取 `shw-issue-gate`；修改前读取 `shw-workspace` 并确认项目、目录、Issue 与所有权。项目外只读，未知修改不覆盖；能力缺失不扩大授权。

# 文档一致性

检查 PRD 的业务规则、角色权限与状态流转是否匹配本次实现；技术文档的接口、数据、依赖与部署是否匹配代码和配置。当前规格与待实现方案分栏/分节，不把计划写成已完成。

追踪 Issue AC → 规格 → 代码/配置 → 体验证据，指出缺失链接、矛盾、无法访问引用与假占位。需要外部知识库的内容先验证检索路径、适用版本与访问；唯一执行约束不能迁出后无人加载。

不重建全量长文档、不要求独立原型、draft-review 或终审。修改与代码同一 Issue/PR；读写边界及未验证事实如实记录。
