# 跨会话协调

发现同文件/API/数据库迁移/部署资源竞争，先读已有Issue评论、PR、所有权记录，确认实际持有者和范围。当前会话保留自己的现场，继续不依赖冲突的部分。

在用户或显式调用的适用流程授权对外留言、且宿主规则允许时，向已确认Issue发送简短冲突事实、方案、当前范围与需要确认的问题，发送后回读。没有发消息授权时准备内容并报告，不能因本技能存在就认为自动获权。

不得修改对方分支、借claim、删除他人目录、未经协调改迁移编号或rebase含未知修改的现场。能在自己范围内安全避让则执行；语义分歧需明确裁决。

协调结果更新自身计划和所有权，恢复前重新检查；旧评论不是永续锁。
