# 公司知识库入口

使用前读取 `shw-issue-gate`，先判定当前仓库的模式和项目外只读边界；知识库查询本身是纯读操作。

默认知识库是 Gitea 仓库 [shw-project/shw-knowledge](https://git.shw.top/shw-project/shw-knowledge)。用户明确给出其他知识库或仓库时，以用户指定的对象为准。本 Skill 是入口指路，不保存知识库内容快照，也不把其他仓库的 README、旧文档或 Agent 记忆当作该知识库的当前内容。

回答或执行依赖公司知识的任务时，先用当前可用的只读 Gitea 工具查看仓库默认分支及目录，再按问题搜索和读取相关文件；也可读取已存在且有权限访问的本地 checkout，但须核对其分支与更新状态。只读取所需文件，记录实际读到的路径和 commit/ref，并在回答中链接到相应仓库文件。具体业务项目的代码、配置和产品文档仍需按该项目当前事实核对；知识库内容不能替代项目实况。

仓库无内容、访问失败或未找到相关条目时，明确说明查询范围和缺口，不猜测知识库的目录、规则或结论。需要新增或修改知识库内容时，先按该仓库自身的 Agent 规范和授权流程处理；在其他项目工作区内仅只读访问它，不跨项目写入。

优先按关键词、技术栈、适用版本检索索引，并核对条目来源、负责人、最后验证 commit/ref 与替代关系。未建立索引时如实说明。知识库只承载经验、示例和历史；权限、工作区所有权、测试时机、候选基线与发布约束保留在随插件分发的执行技能或其强制加载 references，不能以未核实知识库代替。
