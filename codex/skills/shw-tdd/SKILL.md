# 测试设计兼容入口

开发阶段必须执行类型检查、适用 lint/静态检查及本次改动涉及的单元与单模块 API 快速测试；全量 E2E、VRT、全量 API 等长周期回归集中到 dev→main 集成。必要构建、部署正常执行，tag 不新增测试阶段；检查通过不能代替人工验收。

断言覆盖可观察行为与重要边界，避免镜像实现、测试无意义可逆低风险改动或单纯查关键词。失败需区分环境问题、已验收预期变化、意外回归和未知；预期变化只更新相应候选断言/基线再复跑。不能为旧测试绿回滚正确行为或删除断言掩盖问题。

插件自身构建/契约测试属于插件维护验证，不应因业务流程阶段限制而不验证分发产物；报告时明确验证对象。
