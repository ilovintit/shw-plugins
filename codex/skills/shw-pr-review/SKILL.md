**项目外只读**：仅可修改当前项目已确认的工作目录（交付时为当前 Issue worktree）；外部路径禁止直接或间接写入。需要修改时先停止，报告路径、原因和拟修改内容，请用户介入并交其他获授权 Agent 或用户手动处理。完整边界及有限运行例外见 `shw-issue-gate`，执行前必须读取。

# PR 自审

读取完整 Issue/评论、产品文档、目标分支差异和所有改动文件，至少完成：

1. 每条 AC 都有实现与人工可判定证据；适用工程行为有对应检查，每项改动都能回指 AC 或必要修复。
2. 行为符合 PRD、所有适用入口原型和架构契约。
3. 权限、输入、错误、并发、幂等、迁移、兼容和回滚没有遗漏。
4. 适用单元/协议/安全测试按 `shw-tdd` 先于实现；API/E2E/VRT 不作为功能 PR 前置，也不得在功能 PR 自动重录基线。
5. `deploy/` 只含声明，不含 kubeconfig、Token、私钥或集群连接文件。
6. 无调试代码、无敏感信息、无无关格式化和越界重构。
7. 本地 build/typecheck 证据新鲜；required 工程检查只引用当前 PR head 的 CI。已有基线回归报告仅作独立参考，不冒充功能验收。

发现问题先修复并重审。审查者不能只读摘要或依赖子任务报告；没有逐项证据不得创建“可合并”结论。
