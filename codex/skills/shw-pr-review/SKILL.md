# PR 自审

读取完整 Issue/评论、产品文档、目标分支差异和所有改动文件，至少完成：

1. 每条 AC 都有实现与测试证据；每项改动都能回指 AC或必要修复。
2. 行为符合 PRD、所有适用入口原型和架构契约。
3. 权限、输入、错误、并发、幂等、迁移、兼容和回滚没有遗漏。
4. 自动测试先于实现设计，测试名称与 test-plan 映射一致。
5. `deploy/` 只含声明，不含 kubeconfig、Token、私钥或集群连接文件。
6. 无调试代码、无敏感信息、无无关格式化和越界重构。
7. 本地 build/typecheck 证据新鲜；测试结论只引用当前 PR head 的 CI。

发现问题先修复并重审。审查者不能只读摘要或依赖子任务报告；没有逐项证据不得创建“可合并”结论。
