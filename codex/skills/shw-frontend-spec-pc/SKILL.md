# PC 端前端视觉与操作逻辑规范

## 概述

本 skill 是 **PC 后台**（Vite + Vue 3 + Element Plus，栈见 **shw-frontend-stack**）的视觉规范与 PC 端操作逻辑落地。通用行为铁律（编辑/详情必须调详情接口、弹窗/表单/列表通用逻辑）在 **shw-frontend-spec-common**，本 skill 不重复，只讲 PC 端的视觉口径与端内差异。

---

## 页面骨架

### 标准列表页布局

```
┌────────────────────────────────────────────┐
│ 面包屑/页签区（如启用）                        │
├────────────────────────────────────────────┤
│ 查询区：筛选表单（≤1 行常用条件 + 展开/收起）   │
│         右对齐：[查询] [重置]                 │
├────────────────────────────────────────────┤
│ 操作区：左（新增/批量操作） 右（刷新/列设置/密度）│
├────────────────────────────────────────────┤
│ 表格区                                       │
│ ├─ 列：业务列… 状态列(标签) 时间列 操作列(右侧固定)│
│ └─ 底部：分页器（右对齐）                      │
└────────────────────────────────────────────┘
```

- 查询区与操作区分开，不混在一行；查询按钮永远在条件区右侧
- 操作列**右侧固定**（`fixed="right"`），列多时业务列可横向滚动但操作列始终可见
- 状态列用 `el-tag` 语义色，不用纯文字堆砌

### 标准表单页/弹窗

- 字段少（≤7 个）用弹窗，字段多用独立页面或抽屉；不要把超长表单塞弹窗
- 弹窗宽度不做统一档位规定，按内容量取合适宽度，同一系统内保持体感一致即可
- 弹窗标题 = 动词 + 对象（"编辑用户"、"新增商品"），不带多余符号
- 长表单分区：用分隔标题或分步，不做一屏 20 个字段的"墙"

## 视觉口径

### 间距与栅格

- 页面内容区四周 padding：**16px**；卡片间距 **16px**；卡片内区块间距 **12px**
- 表单 label：默认右对齐、top 对齐用于长 label 或窄弹窗；同一表单内不混用
- 表单横向排列：弹窗内单列为主，宽表单双列（`el-row`/`el-col` 24 栅格，双列各 12）

### 字号与层级

| 层级 | 字号 | 字重 |
|------|------|------|
| 页面标题 | 16px | 600 |
| 卡片/区块标题 | 14px | 600 |
| 正文/表格内容 | 14px | 400 |
| 辅助说明文字 | 12px | 400（次要色） |

不出现 14px 以下的正文内容；12px 只用于辅助信息。

### 颜色

- 主题色/语义色**只用 Element Plus 默认语义体系**（primary/success/warning/danger/info），不自造第三套色值
- 状态语义统一：成功/启用=success，失败/停用=danger，待处理/进行中=warning，草稿/禁用=info；同一系统内一个业务状态只对应一种颜色
- 大面积背景只用 neutral 灰阶（页面底 `#f5f7fa` 量级），内容容器用白色卡片

### 表格视觉

- 表头背景浅灰、字重 600；单元格默认不加边框风（`border` 仅用于列对齐复杂的表）
- 单元格超长文本省略号 + `show-overflow-tooltip`，不撑破列宽
- 金额/数量右对齐，时间统一格式 `YYYY-MM-DD HH:mm:ss`（仅日期场景 `YYYY-MM-DD`）
- 操作列按钮：≤3 个平铺文字按钮；>3 个收进"更多"下拉；danger 操作加 `confirm` 或保持二次确认弹窗

## PC 端操作逻辑落地

（通用铁律见 shw-frontend-spec-common，以下是 PC 端口径）

- **编辑/详情 = 弹窗或抽屉打开时调详情接口**，行点击传 `row.id`，不传 `row`
- 查询区"重置"清空全部条件并**重置页码后自动查询**
- 表格选择列用 `el-table` 多选 + `row-key`（无稳定 ID 的列表不做批量操作）
- 弹窗用 `el-dialog` + `destroy-on-close` 或关闭时手动 resetFields，二选一，不裸关
- 删除/危险操作用 `ElMessageBox.confirm`，文案带对象名
- 表格数据变化后保持筛选条件刷新（详见通用规范列表章节）
- 页面级 loading 用 `v-loading` 指令，不用全屏遮罩盖查询区

### 键盘与焦点

- 弹窗打开焦点落到第一个输入项；ESC 走统一关闭拦截（未保存修改需确认）
- 表格内回车提交查询：查询表单 `@keyup.enter` 触发查询

---

## 红旗 — 停下

- 编辑弹窗直接吃列表 `row`（严重，见通用规范）
- 操作列不固定，横向滚动后看不到操作
- 状态用彩色文字而不是 `el-tag`
- 一个表单混用 label 对齐方式
- 弹窗关闭不重置，二次打开残留数据

## 审计应用

对 PC 端项目做逐页审查时，按"页面骨架 → 视觉口径 → 操作逻辑"三层核对；数据来源审计（编辑/详情是否走详情接口）优先级最高，产出逐页违规清单（页面文件 + 违规项 + 级别）后统一修复。
