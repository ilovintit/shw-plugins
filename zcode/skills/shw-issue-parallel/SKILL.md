**项目外只读**：仅可修改当前项目已确认的工作目录（交付时为当前 Issue worktree）；外部路径禁止直接或间接写入。需要修改时先停止，报告路径、原因和拟修改内容，请用户介入并交其他获授权 Agent 或用户手动处理。完整边界及有限运行例外见 `shw-issue-gate`，执行前必须读取。

# 单 Issue 内部并行

只有当前 Agent 工具支持且用户/宿主规则允许委派时才使用。

可并行条件：同一 Issue 内存在两个以上互不依赖的任务，修改文件集合互斥，输入契约和验收标准完整。派发必须写清目标、范围、禁止项、上下文、验证与回传格式；协调者亲自检查 diff和证据。

必须串行：

- roadmap 中不同 Issue；
- 同一文件或同一公共契约；
- 前项输出决定后项设计；
- 数据迁移与依赖实现；
- 产品范围仍需用户裁决。

子任务不创建自己的 Issue/分支/PR，不合并代码，不声称 CI。并行只是单 Issue 实现细节，不能改变 Issue:分支:PR = 1:1:1。
