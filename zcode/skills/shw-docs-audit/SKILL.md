# 当前状态审计

读取实际 Git状态/项目模式、Agent规范、PRD/技术文档、workflow依赖图、required contexts、部署触发和制品映射。保护未知修改；只修改明确授权范围。

逐项报告现状、目标、证据、变更和未验证项：

- 模式是否明确；无模式不自动接管，旧ignore冲突需明确迁移。
- 工作区提供者可选，`shw-workspace` 的所有权检查始终执行；不能因本地插件缺失绕过占用。
- PRD/技术方案够用，直接实际实现，无独立原型；当前规格和计划分开，代码文档同变更。
- 测试与开发、集成、发布、部署解耦：单元、API、E2E、VRT、回归及冒烟均仅在用户明确要求后，于独立 `test` 分支的固定提交执行。普通 push/PR/tag/部署和推送 test 分支本身不触发测试；未测试不阻挡已授权发布。必要构建/编译、静态与配置检查、来源核对正常执行，不得借“检查”名义运行测试；构建成功不代表测试或人工验收通过。
- 测试工作流仅workflow_dispatch且强制test分支；push/PR/tag/schedule及部署依赖不触发测试。测试结果/基线不参与发布聚合或required checks；来源漂移仍需核对。
- main日常集成与tag/审批发布分离；复用digest有来源证据；未授权不改业务CI/Fleet。
- 项目配置外置、无凭据、引用可访问；schema/images等可执行契约仍版本化分发。

历史版本号不再逐段重放迁移。旧规则与当前契约冲突时先定位实际使用点，再在授权内按当前契约调整；不凭旧文档恢复退役技能。
