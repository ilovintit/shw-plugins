# 工具特定配置：gitea 凭证获取路径（按需加载子文件）

**操作责任**：本文用户级配置、shell profile、插件安装目录和外部缓存的修改示例由用户或其安排的其他获授权 Agent 执行。当前项目 Agent 仅可读取并提供操作说明；需要外部修改时按 `shw-issue-gate` 停止并请用户介入。插件程序正常维护自身状态/后端缓存不授权 Agent 手改这些文件。

本文件是 `shw-issue-gate` 建单步骤的通道兜底说明。主文保持工具无关，各 agent 工具的凭证获取路径差异集中在这里。

## 安全声明

**本文件不含任何真实凭证（token、密码），也不含任何真实主机名。** 它只是"去哪里找凭证"的路径指路文件，随插件源码入库。任何时刻都不要把真实 token / 内部主机名写进本文件或 SKILL.md——凭证只存在于各工具自己的凭证配置中。

## 获取方式

各 agent 工具的 gitea 凭证配置方式不同，**按你当前所用的 agent 工具的配置文档获取 host + token**：

- 优先走 gitea-mcp：MCP server 自带凭证配置，建单直接经 MCP 工具完成，无需手动取 token
- gitea-mcp 不可用（未挂载 / 调用失败）时，才走 REST API 兜底：此时需要 host 地址与访问 token，两者都从当前工具的 gitea 凭证配置中读取，不要向用户索要明文 token

## 配置示例占位

具体的凭证存放路径与配置格式示例，由**所用工具的插件配置文档**承载，不在本文件内维护。工具演进时以对应工具的配置文档为准，本文件只保留指路职责，避免与各工具文档产生双源漂移。
