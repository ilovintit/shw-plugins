**执行前置**：先读 [适用模式与权限](../shw-issue-gate/SKILL.md)。仅修改当前已确认项目工作目录；项目外只读，未知修改不得覆盖。涉及写入先按 [工作区能力契约](../shw-workspace/SKILL.md) 确认所有权，不强制依赖本地 worktree 插件。

# 按证据调试

1. **复现与取证**：记录入口、步骤、实际/期望、commit、制品、环境与时间。读取错误栈、相关 diff、有限日志与依赖状态；不能复现时标明不确定，不凭猜测修复。不读取凭据或输出敏感数据。
2. **对比与定位**：对照当前版本能工作的路径；逐边界检查输入、输出、配置和状态，区分环境故障、已验收预期变化、意外回归与未知。环境问题先修环境，不改业务来迁就旧断言。
3. **单一假设**：写明根因、支持证据和最小改动，一次隔离一个变量。观察不支持假设时回到取证，不叠加猜测补丁；多次失败时重新评估依赖或架构，报告未决点。
4. **修复与交付**：修根因，同一变更同步相关 PRD/技术文档，部署实际体验，记录用户人工验收。没有体验或验收证据时不宣称已验收。

**测试时机**：开发阶段必须执行类型检查、适用 lint/静态检查及本次改动涉及的单元与单模块 API 快速测试；全量 E2E、VRT、全量 API 等长周期回归集中到 dev→main 集成。必要构建部署正常执行；快速检查通过不替代人工体验，tag 不新增测试阶段。

集成阶段按 [测试契约](../shw-test-spec/SKILL.md) 对冻结候选运行自动检查。已验收预期变化只更新对应候选断言/基线并重跑；意外/未知回归定位修复，若改变行为则返回体验及人工验收。禁止为旧测试变绿回滚正确实现、全量接受快照或删断言掩盖问题。无旧基线、候选晋升、并发变更规则均由测试契约统一定义。

## 按需技术

- 调用链深处出现错误值：先读 [根因追踪](root-cause-tracing.md)。
- 已定位根因且需要边界防护：先读 [分层防护](defense-in-depth.md)。
- 集成测试发生时序抖动：先读 [条件等待](condition-based-waiting.md)。

教程适用于开发快速调试及集成回归，按影响范围选择执行；构建、运行状态观察、人工体验和自动测试分别报告。完成报告列根因、修改、已获得证据与未验证项，遵循 [证据契约](../shw-verify/SKILL.md)。
