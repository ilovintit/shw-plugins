# 按需测试设计

测试与开发、集成、发布、部署解耦：单元、API、E2E、VRT、回归及冒烟均仅在用户明确要求后，于独立 `test` 分支的固定提交执行。普通 push/PR/tag/部署和推送 test 分支本身不触发测试；未测试不阻挡已授权发布。必要构建/编译、静态与配置检查、来源核对正常执行，不得借“检查”名义运行测试；构建成功不代表测试或人工验收通过。

本入口不强制先写测试或自动复测。用户明确要求测试设计时可维护计划与断言；只有请求包含执行时才按 `shw-test-spec` 在test固定候选运行。断言覆盖可观察行为，避免镜像实现或机械检查文案。

失败在测试任务内分类取证，不为旧断言绿而回滚正确实现或删除断言。基线更新按用户确认的预期行为进行，不绑定发布。插件自身维护同样不自动触发测试；必要构建及静态检查与测试执行分别记录。
