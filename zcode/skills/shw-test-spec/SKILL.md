先读 shw-issue-gate 和 shw-workspace，确认项目、目录、来源 SHA 与工作区所有权。测试与开发、集成、发布、部署解耦；未测试不阻挡已授权发布，必要构建、静态和来源检查保留。

# 本地独立测试

1. 读取本次用户请求、测试类型、模块/文件/页面范围及固定源码 SHA。计划、修复、发布和继续均不隐含测试请求，不自动扩大范围。
2. 在专用 Mac mini 已确认所有权的 clean 本地隔离工作区执行，不创建线上 test 快照、不触发远端 workflow、不伪造 CI 变量。原 test 分支历史保留，不能强推、删除或接管。
3. Mac mini 安装可选独立 shw-local-test 插件，读取其运行指南，使用程序维护的主机端口登记和 project+suite 租约。缺插件/登记/归属证据时先报告，不能用手写共享文件、随意端口或云工具绕过。
4. 运行项目实际入口；中间件项目独占，同项目 suite 分 PostgreSQL 库、Valkey DB/key 前缀、RabbitMQ vhost/silo bucket。开发 K8s 和生产数据不用于本地测试。详细契约见 [执行](references/execution.md)。
5. 记录请求、源码 SHA/tree、主机/平台、工具链/镜像版本、资源、命令、退出码、日志及未覆盖项。报告留本地，不给 dev/main 写测试状态。缺基线、失败和未执行不自动阻挡发布。

基线按平台/浏览器/字体/主题固定、按页面模块生成候选，用户认可后晋升；禁止全量接受、删除断言、扩大阈值掩盖回归。H5 结果不能代表小程序或真机。

本插件统一流程，不替用户安装 Mac 插件、修改用户配置或跨项目迁移业务 workflow。各项目接入与线上入口退役须在该项目授权下实施。
