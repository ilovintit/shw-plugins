盘点 PRD 完成度：逐条读验收标准，每条独立取证后判定，产出核对报告（达成附证据 / 部分达成 / 未动）。PRD 是版本粒度的需求契约，完成度不记账——PRD 里没有执行记录，完成度靠本命令现场取证得出（读取式，不是记录式）。

任何时候合法：执行中看进度、发版前摸底、发版后复盘交付差异。已发版的 PRD（文档头部有 `> 已发版：` 行）盘点完全合法——复盘"承诺了什么 vs 实际交付了什么"是有价值场景。与 /shw-prd-release 的边界：release 发版时内嵌自己的重验（不采信历史盘点报告），本命令的报告不是发版依据。

---

**输入**：`/shw-prd-audit` 后的参数是版本号（如 `v2.3`，对应 `docs/prd/v2.3-*.md`；未带 v 前缀时先归一化为带 v 形态再匹配）。

**步骤**

1. **定位 PRD 文件**

   - **参数未提供**：列出 `docs/prd/` 下的 PRD 文件（`ls docs/prd/`，目录不存在则提示尚无任何 PRD、起草走 /shw-prd-draft）让用户指定一个，**不自行挑选"当前版本"**。

   参数有版本号时，按前缀 glob 定位：

   ```bash
   ls docs/prd/<版本>-*.md
   ```

   - **恰一个** → 用之（`<版本>-` 要求版本号后紧跟 `-`，查 v2.3 不会误匹配 v2.30 的文件）
   - **零个** → 提示该版本 PRD 不存在，起草走 /shw-prd-draft，停止
   - **多个** → 列出全部让用户指定，不猜

2. **逐条独立取证**

   通读 PRD 的需求清单，逐条验收标准**独立取证**后判定——每条单独取证，不因同一需求的其他条目达成而搭车判定。

   取证来源合法集合（超出此集合的来源不得作为判定依据）：

   | 取证来源 | 说明 |
   | --- | --- |
   | 现场跑命令 | 执行命令比对结果 |
   | 发请求 | 实际发请求看响应 |
   | 读代码 | 读到检查点（关键实现位置） |
   | 查 git log | 需求对应 change 的提交 |
   | 查 `.changes/archive/` | change 归档状态 |
   | 查 `.roadmaps/` | roadmap 执行轨迹（**只读**，不修改） |

3. **独立取证纪律（硬纪律）**

   - **基于当下事实取证**：不采信"应该做完了"的记忆，不采信既往盘点报告——既往报告只能当线索（提示去查哪里），判断必须现场重新取证
   - **证据必须出示**：宣布任何条目达成必须附证据（命令输出 / 响应 / 代码位置），禁止裸判
   - **目检不越界**：目检类标准（界面/体验）取证到代码级检查点为止，标注"待用户目检"，不得自行宣布通过——这类结论只有用户能下

4. **产出核对报告**

   逐条列出判定，报告**只在对话输出，不写任何文件**。格式示例（简短）：

   ````markdown
   # PRD vX.Y 完成度核对报告

   ## 需求 1：<名称>

   - 验收标准 1：**达成**——证据：请求 `GET /api/orders?page=2` 返回 200 且数据与第 1 页无重复（响应片段粘贴于此）
   - 验收标准 2：**部分达成**——差距：分页已实现但第 2 页起 offset 计算错误返回空列表（代码位置：`xxx/service.go:88`）
   - 验收标准 3：**待用户目检**——代码级已确认翻页参数透传正确（`xxx/List.vue:42`），视觉表现需用户目检

   ## 需求 2：<名称>

   - 验收标准 1：**未动**——`.changes/archive/` 无对应 change，`git log` 无相关提交，代码无对应实现

   ## 汇总

   - 达成 X 条 / 部分达成 Y 条 / 未动 Z 条 / 待目检 N 条（共 M 条）
   - 待目检清单：需求 1 验收标准 3（分页控件视觉）…
   ````

   部分达成必须写清差距是什么；未动也附取证说明（查了哪里、没有查到什么）。

**约束**

- **零写副作用**：不改 PRD、不改任何文件（含 `.roadmaps/`、`.changes/`）；报告只在对话输出，不落盘
- **不采信记忆与既往报告**：完成度判断只认当下现场取证，既往盘点报告只能当线索
- **目检不越界**：界面/体验类结论只能由用户下，agent 到代码级检查点后标注"待用户目检"
- **多文件匹配必让用户选**：定位到多个 PRD 时列出全部让用户指定，不猜
- **`.roadmaps/` 只读**：查 roadmap 执行轨迹时不做任何修改
- git 查询只读（`git log` 等），不执行任何 git 写操作
