执行前必须读取 `shw-issue-gate`；修改前读取 `shw-workspace` 并确认项目、目录、Issue 与所有权。项目外只读，未知修改不覆盖；能力缺失不扩大授权。

# 恢复记录

只在跨会话需要时更新项目 Journal/Issue：目标、当前分支/目录、所有权标识、PR、精确 SHA、已做/待做、阻塞、决策和证据链接。未知项明确标注。

恢复前重读 Git 状态、占用、PR当前HEAD和目标基点；不能凭旧日志覆盖未知修改或复用过期CI。业务真相仍在 PRD/技术文档；不复制凭据、auth、sessions 或完整业务数据。

结束时分别记录实现、构建、体验、人工验收、集成测试和发布状态。宿主任务归档只按宿主能力与授权，不能等同分支/工作区清理。
