# Mac mini 本地测试

此插件只安装在专用 Mac mini；主 SHW、MCP、Worktree 的通常三包组合保持不变。本插件通过 Python 3 标准库 CLI 管理本机状态，不注册 MCP、不安装依赖、不修改用户配置、不启动 Docker、不杀进程。读取 [运行指南](README.md) 和项目 `.shw/test-runtime.json` 后操作。

测试必须有用户本次明确请求、范围及精确源码 SHA。开发、修复、集成、发布和部署不隐含测试授权；测试也不成为发布门禁。不创建、推送或使用线上 test 分支工作流。已有 test 历史保留，禁止强推或删除。测试从已确认所有权的本地隔离工作区执行，固定 clean SHA/tree；发现代码变化立即停止，修复仍走项目 Issue 流程。

1. 读取项目实际入口、工具链与资源清单。端口登记由本插件 `ports.py` 管理，Agent 不手改主机登记表。首次 reserve 必须在用户已授权该 Mac 主机接入后执行；不能在当前其他机器代登记。登记使用稳定项目 ID 和主仓库真实路径，多 worktree 共享。导入现有项目端口必须逐项确认，未知监听不覆盖、不终止。
2. 用 `list` 核对登记，再 `reserve` 原子申请。Compose 只向 127.0.0.1 绑定登记端口；跨项目独立实例/volume/network。同项目 E2E/VRT 可复用中间件，但 PostgreSQL 分库（18、Asia/Shanghai）、Valkey 不同 DB 且 key 前缀、RabbitMQ 不同 vhost、silo 独立测试 bucket。资源名全部显式白名单，禁止共享 dev/生产库。
3. 用 `acquire` 取得项目+suite 租约，记录返回私有 token；同 suite 跨 worktree 互斥，不同 suite 只有端口/数据/目录完全隔离才并行。租约不是服务就绪证明，启动前检查监听及容器项目标签；已运行中间件需验证确属该项目、端口/镜像一致且健康。仅凭端口可连接不足以确认归属。
4. 按本次范围执行项目自己的命令；不伪造 CI 变量。缓存、临时文件、日志、截图、报告落当前测试工作区 `.cache/local-test/`；工具不支持定向时停止并交用户配置。Node/Go/Playwright 遵从项目锁定版本，不能拿试点机器当前版本替代标准；内部镜像按已核验 digest/架构引用，缺 ARM64 不自动换来源。
5. 退出时只关闭本轮拥有的 API/前端子进程，保留项目中间件；只清理本 suite 白名单资源，不执行全机 prune、FLUSHALL、共享 schema/vhost 删除。确认停止后用 token `release`。异常/断线保留租约，先核对进程、容器、工作区及报告，再由持有者释放；遗失 token 由用户维护者处理，不手改/偷取状态。
6. 记录请求、host、OS/CPU、源码 SHA/tree、工具版本、镜像 digest、端口、隔离资源、命令、起止时间、退出码、报告路径及未覆盖项。缺基线标 unbaselined，环境错误标 execution-error，变化标 obsolete-target；未运行不写通过。

Mac/Linux/微信开发者工具/真机基线分平台。OS、浏览器、字体、缩放、主题与基线 revision 固定；按页面/模块生成未审阅候选，用户认可后才晋升。禁止全量接受、删断言、扩大容差或遮罩掩盖回归。#482 的 0.01 颜色阈值和 262 张截图只是 CCL 试点候选，不能自动升为全局标准。H5 通过不代表原生小程序或真机通过。

端口登记只防止已登记调用间的冲突，探测结束到监听建立仍有竞争窗口；项目启动器必须处理 bind 失败并核对真实监听归属。此插件提供流程和资源管理，不是任意项目测试的一键执行器。
