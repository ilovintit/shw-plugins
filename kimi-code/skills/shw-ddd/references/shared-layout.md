# Shared 模式

Shared 放**跨模块共享**的代码，同样遵循四层结构。

```
shared/                           ← 跨模块共享（物理根路径由各框架约定）
│
├── interfaces/                   ← 全局入口（跨模块共享）
│   ├── http/                     ←   全局请求处理器（如健康检查）
│   ├── middleware/               ←   全局请求管道装配（把基础设施中间件挂到链上）
│   └── command/                  ←   全局 CLI 命令（数据填充、缓存清理等）
│
├── application/                  ← 跨模块共享的应用层
│   └── enum/                     ←   共享应用枚举（如全局错误码）
│
├── domain/                       ← 跨模块共享的领域层
│   ├── enum/                     ←   共享领域枚举（通用业务状态码）
│   └── service/                  ←   共享领域服务（如密码生成器）
│
└── infrastructure/               ← 跨模块共享的基础设施
    ├── service/                  ←   共享基础设施服务（会话、短信、存储等组件接入）
    └── enum/                     ←   基础设施枚举（如基础设施错误码）
```

### Shared 的使用原则

- **只有真正被多个模块共享的代码才放这里**。单模块使用的代码留在自己模块内。
- **Shared 不是垃圾桶**。如果不确定，先放模块内。等第二个模块需要时再提取。
- **提取时机**：第二处复用发生时再下沉到 Shared，不要提前抽象。

| Good | Bad |
|------|-----|
| 第二个模块需要时才下沉到 Shared | 为了"复用"提前抽到 Shared |
| 单模块代码留在模块内 | 把可能复用的代码都堆进 Shared |
