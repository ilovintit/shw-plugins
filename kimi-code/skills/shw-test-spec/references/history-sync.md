# 集成来源与独立测试记录恢复

恢复集成时重新读取 PR HEAD、dev 来源、main 基点和预合并 tree，核对 Issue 范围与授权。正常 merge 后记录实际 main SHA、父提交和 tree；身份变化更新来源记录，不触发测试。必要构建及制品复用仍须有准确源码与完整构建输入证据。

恢复独立测试时读取用户主动请求、test HEAD/tree、业务来源 SHA、目标 revision/digest、配置、fixture 与基线 revision。任一变化使旧报告失效，不把另一快照的结果标为本次通过。重新运行仅在本次主动请求范围内于 test 分支手动执行；push test 本身不构成请求。

test 快照、测试结果和基线不自动晋升到 main，不默认 test→main，不阻挡已授权集成、发布或部署。基线维护和额外测试需要明确范围与授权；未体验/未验收如实记录。
