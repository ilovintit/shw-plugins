执行前必须读取 `shw-issue-gate`；修改前读取 `shw-workspace` 并确认项目、目录、Issue 与所有权。项目外只读，未知修改不覆盖；能力缺失不扩大授权。

# 集成到 main

读取 [候选来源契约](references/candidate.md)、`shw-verify`。冻结已授权范围的 dev SHA、main 基点和预合并 tree，创建或复用集成 PR，保护未知修改与并行占用；未来 dev 推送不自动纳入。

集成仅做代码/文档审查、必要构建/编译、配置与来源核对，不触发或等待单元、API、E2E、VRT、回归或冒烟。人工体验可按用户安排在生产发布后进行；未体验/未测试如实记录，不默认阻挡明确授权的集成和发布。

在当前授权及实际非测试合并要求满足后正常合并，核验父提交、tree、SHA与候选一致。候选或目标变化时重算差异及构建输入，不因此触发回归。保留实际构建来源与main提交映射，不能把历史构建结果套在新内容上。

`test` 分支是用户主动测试的独立路径，不必先经过test，也不自动从test晋升到main。测试基线不绑定集成放行，不自动更新。需要测试时按 `shw-test-spec` 的明确请求执行。

存量测试required checks须在该项目授权范围内正常迁移工作流/保护配置；不得force合并、伪造成功或把skipped称为passed。插件更新不等于其他仓库已迁移。
