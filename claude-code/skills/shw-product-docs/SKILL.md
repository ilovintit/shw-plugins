执行前必须读取 `shw-issue-gate`；修改前读取 `shw-workspace` 并确认项目、目录、Issue 与所有权。项目外只读，未知修改不覆盖；能力缺失不扩大授权。

# 产品与技术文档

managed 项目用 `docs/prd/product.md` 保存当前目标、范围、关键业务规则、权限、状态和可体验结果；`docs/architecture/index.md` 索引必要接口、数据、服务边界与部署配置。轻量模式保留项目自身目录。

初版只写足够实施当前切片的内容，直接实现可体验版本，不设独立原型阶段。当前已实现规格与待实现方案明确区分，Issue仅保留摘要/AC/链接，不能成为第二份规格。

每个 Issue：业务逻辑/权限/状态流转变化同步 PRD；接口/数据/架构变化同步技术文档，和代码同一个变更交付。只改表现且未改变契约时说明不需规格更新的依据。体验反馈改变行为时更新相应规格与验收范围。

项目特定宿主/分支/环境/前缀/域名/工具链/测试入口/制品映射外置 `.shw/project.yaml` 和部署文档；只记录配置引用，不写秘密。按需 reference 随插件版本，知识库先验证可访问与版本，关键执行约束仍由入口强制加载。
